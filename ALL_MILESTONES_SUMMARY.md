## What This Project Does

Executes a single atomic Solana transaction containing:

1. SOL transfer from Wallet A to Wallet A (1 million lamports = 0.001 SOL)
2. SOL transfer from Wallet A to Wallet B (1 million lamports = 0.001 SOL)
3. Token transfer from Wallet A to Wallet A (1 million tokens)
4. Token transfer from Wallet A to Wallet B (1 million tokens)

All 4 instructions execute together atomically:
- All succeed: Transaction confirmed
- Any fails: Entire transaction reverts

## Technology Stack (No SDKs)

Core only:
- Node.js (CommonJS)
- Built-in crypto (SHA-512, Ed25519)
- TweetNaCl.js (for signing only)
- HTTPS for RPC calls

Zero Solana SDK dependencies in main code:
- No `@solana/web3.js`
- No `@solana/spl-token`

## Key Technical Achievements

### Account Deduplication
```
Before: 10 accounts (2+2+3+3 from instructions)
After:  4 accounts (Wallet A, Wallet B, System, Token)
```

### Account Ordering
```
Order 1: All signers first
         - Wallet A (signer, writable)
Order 2: Writable non-signers
         - Wallet B (writable, non-signer)
Order 3: Readonly accounts
         - System Program (readonly)
         - Token Program (readonly)
```

### Message Compilation
```
Header:       3 bytes   (signer counts)
Accounts:     129 bytes (4 * 32 + 1)
Blockhash:    32 bytes
Instructions: 76 bytes  (4 instructions)
Total:        240 bytes
```

### Transaction Assembly
```
Signature count:  1 byte
Signature(s):     64 bytes (Ed25519)
Message:          240 bytes
Total:            305 bytes
```
